The Cloud Making Machine is the first plugin I ever designed.
It follows the signal path of a fx chain I have used for many years.
It is intended to be an fx unit more than a mixing tool, pushing you to use your ears instead of numerical references.
It sounds quirky, digital and nasty; mapping it to a controller may result in a great sound design session.
Have fun !
